# RELEASE NOTES — 0.1.0

Первая играбельная alpha SKYFORGE.

## Есть

- Парящий остров SKY-001 с лугом, карьером и прудом
- Физический персонаж, touch-управление, third-person камера
- Grab / throw, рубка дерева, добыча камня
- Мастерская и конструктор с snap/joints
- Чертёж тележки, пуск, сиденье, езда, выход
- Флора, ветер, день/ночь, лёгкая погода
- Три вида фауны и ночные тени, боящиеся света
- Лёгкое выживание и data-driven крафт
- Save/load, офлайн preview, Android CI/подписи

## Нет / позже

- Летающий корабль
- Полноценный визит на дальние острова
- Носимый планер как отдельный предмет
- Воксельная раскопка острова

## Установка

Скачайте `skyforge-0.1.0.apk` из GitHub Actions artifact.  
Release публикуется только вручную через `workflow_dispatch`.

## Стабилизационный проход (device stabilization)

- Исправлен freeze ~5–7 с после старта: необработанное исключение убивало RAF-цикл.
  Найденные броски: Rapier WASM-паника в fauna (доступ к удалённому телу фрукта),
  `setCcdEnabled` на RigidBody (не существует в rapier 0.14), транспонированный
  heightfield (коллайдер острова не совпадал с визуалом), raycast'ы до первого
  physics step, колёса-цилиндры не на оси качения, несовпадение портов в чертеже
  тележки. RAF-цикл теперь защищён try/catch — одна ошибка не вешает игру.
- Камера больше не проходит под terrain: spring-arm с двумя Rapier-лучами,
  запрет y < terrain, workshop в camera-collision set. Проверено свипом 1728 углов.
- Остров получил видимый объём: конические склоны за обрывом, скальная оболочка
  и днище — при взгляде сбоку/снизу читается масса, а не тонкая плоскость.
- Тележка: физически едет 24+ м, рулит, exit возвращает ходьбу.
- Headless-соаки idle/night/drive/chaos 130 с: 0 исключений, счётчики без роста.
