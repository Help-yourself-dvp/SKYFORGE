# RELEASE NOTES — 0.1.0

Первая играбельная alpha SKYFORGE.

## Есть

- Парящий остров SKY-001 с лугом, карьером и прудом
- Физический персонаж, touch-управление, third-person камера
- Grab / throw, рубка дерева, добыча камня
- Мастерская и конструктор с snap/joints
- Чертёж тележки, пуск, сиденье, езда, выход
- Флора, ветер, день/ночь, лёгкая погода
- Три вида фауны и ночные тени, боящиеся света
- Лёгкое выживание и data-driven крафт
- Save/load, офлайн preview, Android CI/подписи

## Нет / позже

- Летающий корабль
- Полноценный визит на дальние острова
- Носимый планер как отдельный предмет
- Воксельная раскопка острова

## Установка

Скачайте `skyforge-0.1.0.apk` из GitHub Actions artifact.  
Release публикуется только вручную через `workflow_dispatch`.
